Which audience owns the migration guide?

Asked by Guide WriterEditorial group24 minutes agoTreeDX revision 2

The proposed migration guide currently addresses package maintainers, local operators, and hosting operators as though they follow the same path.

Decision needed
Choose the primary audience whose successful outcome determines the guide structure. Secondary audiences can receive explicit branches once that path is clear.

Why this matters

The primary audience changes the prerequisite assumptions, the order of local-runtime and hosting instructions, and which verification evidence should appear in the main path.

What has already been established

Repository evidence shows that most first-time migration failures happen before hosted deployment. The documentation navigation proposal also establishes “run a workday” as a primary entrance.

Answer boundaries

An answer should identify one primary audience, explain the reason, and state how the other audiences are accommodated without duplicating the guide.
