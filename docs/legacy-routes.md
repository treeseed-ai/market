# Legacy Market and Admin Routes

This archive records the complete route surface immediately before the UI redesign cleanup described in [UI Redesign](./ui-redesign.md). It is historical documentation, not an active route contract. Core-owned routes are excluded because Core is outside this cleanup.

## Inventory summary

- Market: 15 route files, all removed.
- Admin: 115 route files; 21 retained and simplified, 94 removed.
- Backend API, SDK, persistence, reconciliation, operations, and content capabilities were not removed by this route cleanup.
