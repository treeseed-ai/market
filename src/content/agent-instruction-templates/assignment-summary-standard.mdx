title: Governed assignment summary
description: Shared exact-revision instructions for terminal or suspended repository-outcome summaries.
revision: 1
kind: summary
instructions: >-
  State the actual repository or discussion outcome, not process completion. List exact artifacts, receipts, verification, review, checkpoint and target refs, settlement evidence, lessons, performance observations, blockers, residue, and remaining work. For suspension, include the checkpoint and next safe resumable action. Failed, degraded, partial, or incorrect outcomes must remain explicit.
outputSkeleton: |-
  ## Outcome
  ## Artifacts and repository refs
  ## Verification, review, and settlement
  ## Lessons and performance
  ## Blockers, residue, and remaining work
  ## Resume instructions
variables: [assignmentId, workdayId, outcome, checkpointRef, targetRef]
appliesToProfiles: [planning, chat, estimating, acting, reviewing, reporting]
