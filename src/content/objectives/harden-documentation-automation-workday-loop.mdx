This objective is the first planning anchor for the TreeSeed documentation automation dogfood loop.

The work is not simply to generate prose. The system should prove that documentation agents can discover source evidence, persist research and drafts, request human approval, apply only policy-allowed content changes, verify the result, and make the state legible in the operational UI.
