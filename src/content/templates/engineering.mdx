The engineering starter is the default guidance layer for software projects. It includes `projectRoot: ..` so a TreeSeed project can live under `docs/` while agents inspect and work from the parent repository.

Use it for application and package repositories that need research, architecture, implementation, review, and release workflows to stay connected.
