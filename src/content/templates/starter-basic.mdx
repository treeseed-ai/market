`starter-basic` is the canonical first-party starter distributed by the TreeSeed Market site. It is always available in project launch so teams can start with a working TreeSeed foundation before adding marketplace templates for more specialized workflows.

## What It Creates

- A hosted TreeSeed project using the Core runtime.
- Standard content collections for objectives, knowledge, decisions, proposals, people, agents, and docs.
- Repository and deployment wiring designed for the Market project launch flow.
- Forms and operational pages that match the default TreeSeed project structure.
- A place for the project's core objective so AI agents can use it as shared context.

## Best For

- New teams creating their first hosted TreeSeed project.
- Operational workspaces that need a reliable project baseline before adding specialized content.
- Projects that should use managed defaults for repository, web, and email hosts.
- Teams that want marketplace templates to extend, not replace, the TreeSeed foundation.

## Included Capabilities

- Astro and TreeSeed Core application structure.
- Cloudflare-oriented web hosting defaults.
- Content-driven project documentation and knowledge organization.
- Agent-ready objective content and workflow conventions.
- Built-in reconciliation support for future template updates.

## Fulfillment Notes

The important architectural property is that the marketplace detail page and the installable template artifact live in the same repository and evolve together. This makes the Core starter the baseline contract for new hosted projects while still leaving room for marketplace templates to provide richer domain-specific project shapes.
