# Filter Signals Through Project Groups

Signal contracts create assignment graph edges. Frozen group membership may filter matching evidence, but a group cannot create work, imply agent membership through a class, or propagate membership across projects.

This page documents `guarantee.agent.graph.filter-signals-through-groups.757`. Its current guarantee status is **planned** pending TreeDX group snapshots and repeatable group-scoped planning scenes.
