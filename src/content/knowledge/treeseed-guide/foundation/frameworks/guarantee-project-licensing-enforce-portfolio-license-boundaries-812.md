# Enforce Portfolio License Boundaries

Public portfolio projects use Apache-2.0 except the Admin API, whose default source license is AGPL-3.0-only with a commercial alternative. The singleton Market API and its content repository remain private and all rights reserved.

This guarantee remains **planned** until protected singleton repository acceptance verifies the private repository and proprietary notice policies.
