# Accounts

## Basic account journey

1. View and edit the profile and email addresses.
2. Configure time zone, appearance, accessibility, and notifications.
3. Inspect and revoke sessions.
4. Export account data.
5. Transfer responsibilities before deleting an account.
6. Use one account across multiple teams.
