# TreeSeed Guide

Start with [Foundation](/t/treeseed/books/treeseed-guide/foundation). It gives people and machine agents the shared purpose, vocabulary, architecture, framework boundaries, TreeDX model, and platform map needed to interpret the guarantee-backed sections that follow.

The operational sections organize TreeSeed's documented promises. Their guarantee pages state expected capabilities; Foundation and the related architecture book explain how those promises fit together.
